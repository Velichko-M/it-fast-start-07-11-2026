Main git commands

  • git status - команда, яка відображає поточний стан змін та файлів
  • git branch - команда, яка показує список гілок в репозиторії
  • git--version - команда, яка показує версію GIT
  • git clone - команда, яка cкачує репозиторій разом зі всіма змінами
  • git add - команда, яка індексує вказаний файл для наступного коміта
  • git commit -m - команда, яка фіксує проіндексовані зміни та зберігає їх в історию версій
  • git push - команда, яка завантажує всі зміни локальної гілки у віддалений репозиторій
  • git checkout -b - команда, яка перестрибує на іншу гілку
